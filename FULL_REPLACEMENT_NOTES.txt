BOOKVERSE v21 FULL REPLACEMENT

HOW TO DEPLOY
1. Replace the contents of your GitHub BookVerse repository with the contents of this ZIP.
2. Keep your existing Streamlit Community Cloud Secrets exactly as they are. Secrets are not included in this ZIP.
3. Commit the replacement. Streamlit will install the unchanged supported requirements and redeploy automatically.
4. Open the app and unlock the existing profile. The existing Supabase-backed SQLite database is migrated in place; profiles and books are preserved.

V21 RECOMMENDATION INTELLIGENCE
- Manual Fast and Deep scans remain fully manual and keep the previous completed set until a new scan succeeds.
- Strict shared request budgets stop provider bursts and bound the work performed by every scan.
- Profile-specific hard rules cover language, audience, descriptions, ratings, length, years, series and excluded book types.
- Focused-to-varied diversity controls enforce per-author and per-genre limits.
- Every personalised recommendation displays Book DNA, a match percentage, reasons and a transparent points breakdown.
- Expanded negative feedback teaches the next scan about wrong genres, age, length, romance and intensity.
- Recommendation Memory can remove one learned preference or clear all feedback.
- Choose My Next Book narrows the last saved set to three finalists without external requests.
- Latest Scan Report shows duration, provider requests, cache hits, candidate counts and rejection reasons.
- Library Health identifies weak metadata and repairs one selected book without losing its shelf, rating, progress or tracking details.
